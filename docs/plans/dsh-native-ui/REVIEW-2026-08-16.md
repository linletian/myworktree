## 1. 批次目的

Start Instance 弹窗与实例 tab 的 UI 一致性问题（issues #68–#71、#73）+ #72 收尾：

- **#68**：窗口较窄时 modal tab 文字换行成一坨。
- **#69**：四个 tab 命名风格不统一（Opencode-Web / Reasonix / Dsh-Web / Terminal），且 `Dsh-Web` 是缩写、`Reasonix` 缺 `-Web` 后缀显得不同类。
- **#70**：实例 tab 上三种 kind 圆角标签（`.badge-oc` / `.rx-badge` / `.badge-dsh`）字号、圆角、padding、字体、字距、颜色来源各不相同。
- **#71**：Terminal tab 缺 `.form-info`，首次使用者不知道它不开 web 服务、不嵌 iframe。
- **#72**：远程访问路径下 dsh-web WS 升级失败导致侧栏「暂无会话」——已由 commit `ec88389`（UX guard：远程禁用）兜底，本批次仅回复 + 关闭。
- **#73**：Start Instance 弹窗整体英文 UI 中，三个 web tab 的 `.form-info` 是整段中文。

## 2. 逐 issue 改动与证据

### 2.1 #68 — tab 文字换行

- `.modal-tabs`：加 `flex-wrap: nowrap` + `overflow-x: auto`（窄窗口横向滚动降级，`scrollbar-width: thin`）。
- `.modal-tab`：加 `white-space: nowrap` + `flex: 0 0 auto`（不压缩、不换行，保持自然宽度）。
- 证据：`TestStartInstanceModalTabLabelsAndWrap` 钉死三条 CSS guard。

### 2.2 #69 — tab 命名统一（方案 A/C）

- 四个 tab 文字改为 **Terminal / OpenCode-Web / Reasonix-Web / DSH-Web**（Title Case + 一致 `-Web` 后缀；DSH 为 DeepSeek Harness 缩写，与 badge `DS`、README 用词一致）。
- `data-tab` 值与后端 kind 映射不变：`terminal` → pty、`opencode-web` / `reasonix` / `dsh-web` 不变（前端 `WEB_UI_KINDS`、`switchStartInstanceTab`、`doStartInstance` 均不受影响）。
- 后端 `Manifest().Label` 同步（休眠字段，无前端消费者，但命名统一必须同源）：
  - `internal/instance/opencode_web/driver.go` — `Opencode-Web` → `OpenCode-Web`
  - `internal/instance/dsh_web/driver.go` — `Dsh-Web` → `DSH-Web`
  - `internal/instance/reasonix/kind.go` — `Reasonix` → `Reasonix-Web`
- 文档同步：README/PRD/API/ARCHITECTURE 均无硬编码 tab 文字（仅历史 CHANGELOG 条目含旧名，不回溯改写）；本批次 CHANGELOG 条目已记录命名方案。
- 证据：`TestStartInstanceModalTabLabelsAndWrap`（四个 tab 文字 + `data-tab` 语义 + 旧名不残留于测试断言之外）；`go test ./internal/instance/...` 全过。

### 2.3 #70 — kind 圆角标签统一

- 三套样式收敛为 `.kind-badge` 基类（10px、`line-height: 1`、`font-weight: 600`、`2px 4px`、4px 圆角、`margin-right: 4px`、系统字体）+ per-kind 仅设颜色的类：
  - `.kind-badge-oc` — `var(--accent-color)` / `#fff`
  - `.kind-badge-rx` — `var(--badge-bg)` / `var(--badge-text)`
  - `.kind-badge-dsh` — 新增 `var(--badge-dsh-bg)` / `var(--badge-dsh-text)`（浅色 `#0969da` / 深色 `#1f6feb`，替换写死的 `#0969da` + monospace）
- 旧类名 `.badge-oc` / `.rx-badge` / `.badge-dsh` 从模板与 CSS 中移除（无其他消费者；`docs/plans/opencode-native-ui/TASK.md` 中的历史提及不回溯）。
- 证据：`TestKindBadgesUnified`（新类出现、旧类消失、主题变量存在）。

### 2.4 #71 — Terminal tab 增加 form-info

- Terminal tab 顶部新增 `.form-info`（英文，与 web tab 同款样式）：
  - 在所选 worktree 里打开 PTY shell（默认 zsh）；
  - 明确「不开 web 服务、不嵌 iframe，等价于直接在 worktree 根目录开新 shell」；
  - 明确 Template / Custom Command 仍然生效（command / env / pre-start），实例停止即会话结束。
- 表单字段顺序与行为不变。
- 证据：`TestStartInstanceModalFormInfosAreEnglish`（Terminal 文案 + 关键句断言）。

### 2.5 #72 — 远程访问 WS 断流（兜底收尾）

- commit `ec88389`（本批次之前已合入）实现三层 UX guard：弹窗禁用 Start + `.form-warning` 提示；`doStartInstance` 纵深 `alert()`；运行中实例全屏遮罩 + 最高优先级警告条；`window.isRemoteAccess()` 集中化。
- 本批次：在 issue 上留言说明兜底方案与根因报告位置（`REMOTE-WS-BREAKAGE.md` §7/§8/§10），并关闭 issue。无代码改动。
- 未做方案 A（WS→SSE 桥）：与「dsh 不做 iframe 内注入」决策冲突，需设计评审，另开 issue 跟踪。

### 2.6 #73 — form-info 及全 UI 文案英文化

- 三个 web tab 的 `.form-info` 改为英文（按 issue 内英文草案，术语与 README 英文版对齐：`reasonix serve` / `dsh web` / `~/.reasonix` / session pool / out-of-scope）。
- 同批次顺带英文化（与 #73「英文 UI 中夹中文」同一类问题，属本批次范围的自然延伸）：
  - dsh 缺失依赖对话框（`index.html` 静态文案 + `dsh_web.js` 动态文案）：标题/正文/三个按钮/二次确认/进度/错误。
  - `dsh_web.js` 全部用户可见字符串：loading 标题、超时标题、四条警告条（远程认证 / 版本与 overlay / 外来活跃会话 / 越界）、操作失败兜底。
  - `opencode_web.js` 同款字符串：loading 标题、超时标题、停止标题、两条警告条。
  - 残留的代码注释中文（`PLAN.md §嵌入形态` 等 §锚点、`串台`）一并改英文，使**整站 UI 源码零 CJK**，可被测试绝对断言。
- 证据：`TestStartInstanceModalFormInfosAreEnglish`（index.html 无中文文案）+ 新增 `TestUICopyIsEnglishOnly`（`/`、`dsh_web.js`、`opencode_web.js`、`reasonix.js`、`framework.js` 五个资源零 CJK 字符 + 每文件关键英文串正向断言）。
