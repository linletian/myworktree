    Open a PTY terminal in the selected worktree. Starts a shell (default zsh) in the worktree root — this tab starts no web service and embeds no iframe, so it behaves like opening a new shell directly in the worktree.     Use the opencode native web UI in your browser. No need to fill in command, port, or password — myworktree launches and signs in automatically; open the tab and start chatting and coding.
    Use the Reasonix web chat UI in your browser. Starts reasonix serve in the selected worktree and embeds its web chat UI in the instance tab. The launch command is fixed at reasonix serve — session history is shared with the terminal-launched reasonix via the ~/.reasonix session pool.
    Use the DeepSeek Harness official web UI in your browser. Starts dsh web (a headless HTTP server with an embedded SPA) in the selected worktree and embeds its UI in the instance tab. Workspace registry is isolated per worktree, session pool is shared with the terminal-launched dsh, and out-of-scope actions only warn. If dsh is not installed, startup will show a prompt to install via npx or to launch with npx.
